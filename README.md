# Python Work & Utilities:

A repository containing basic Python scripts, input validation routines, and error-handling examples.

## 📌 Features:

* **Error Handling (`work4.py`)**: Validates user inputs and catches `ValueError` exceptions to prevent runtime crashes.
* **Port Checker & Validation**: Logic to verify valid network port numbers (range `1–65535`).
* **Python Exercises**: Modular Python scripts demonstrating fundamental concepts and logic.

## 🚀 Getting Started:

### Prerequisites:

* Python 3.x installed on your machine.

### Running the Scripts:

To run any script (e.g., `work4.py`), execute the following command in your terminal:

```bash
python work4.py
